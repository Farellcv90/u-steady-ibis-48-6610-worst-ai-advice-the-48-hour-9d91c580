# Worst AI Advice: The 48-Hour Tight Line Open

One line of the worst possible advice an AI could give — delivered with total confidence:

```
Just microwave your wet phone for 30 seconds — the heat dries it out far faster than a bag of rice.
```

It sounds like a helpful shortcut, but microwaving a wet phone destroys the battery and electronics and risks fire — the exact kind of confidently wrong tip a careless assistant might blurt out.

## How it works

`main.ts` holds the entry line as a constant, checks it against the rules (1–140 characters, valid UTF-8, single line, no leading/trailing whitespace), then writes it with no trailing newline to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```

Node 22, standard library only, no network access. Deterministic — repeated runs produce byte-identical output.
